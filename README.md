# Yandex Disk MCP Server

MCP-сервер, который даёт Claude доступ к твоему Яндекс.Диску: список файлов,
инфо о файле, ссылка на скачивание, загрузка по URL, создание папок,
удаление, публичные ссылки.

## Шаг 1. Получить OAuth-токен Яндекс.Диска

1. Зайди на https://yandex.ru/dev/disk/poligon/ — это "полигон" (тестовая
   консоль), там сразу можно получить токен для своего аккаунта одной
   кнопкой ("Получить OAuth-токен").
   Либо создай своё приложение на https://oauth.yandex.ru/client/new с правами
   `cloud_api:disk.read` и `cloud_api:disk.write`, и пройди OAuth сам.
2. Сохрани токен — он понадобится на шаге 3.

## Шаг 2. Выложить код на GitHub

1. Создай новый **приватный** репозиторий на GitHub (например `yandex-disk-mcp`).
   Приватный — потому что в коде нет секретов, но лучше не светить лишний раз.
2. Залей туда содержимое этой папки (`index.js`, `package.json`, `README.md`).

## Шаг 3. Задеплоить на Render (бесплатно)

1. Зайди на https://render.com, зарегистрируйся (можно через GitHub).
2. New → Web Service → выбери свой репозиторий `yandex-disk-mcp`.
3. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. В разделе **Environment** добавь переменные:
   - `YANDEX_DISK_TOKEN` = токен из шага 1
   - `CONNECTOR_SECRET` = придумай длинную случайную строку (например,
     сгенерируй через `openssl rand -hex 24` или любой генератор паролей).
     Она защищает сервер — без неё запросы отклоняются.
5. Нажми Deploy. Через пару минут Render даст тебе адрес вида
   `https://yandex-disk-mcp-xxxx.onrender.com`.

   ⚠️ Бесплатный план Render "засыпает" после ~15 минут простоя и
   "просыпается" 20–30 секунд при первом запросе — это нормально для
   личного использования.

## Шаг 4. Подключить в Claude

1. В Claude.ai: **Settings → Connectors → Add custom connector**.
2. URL: `https://твой-адрес-на-render.onrender.com/mcp/ТВОЙ_CONNECTOR_SECRET`
   (полный адрес с секретом на конце — это и есть "пароль" сервера).
3. Сохрани — Claude подключится и подтянет список инструментов.

## Доступные инструменты

- `list_files` — список файлов/папок по пути
- `get_file_info` — метаданные файла
- `get_download_link` — временная ссылка на скачивание
- `upload_from_url` — скопировать файл на Диск по внешней ссылке
- `create_folder` — создать папку
- `delete_resource` — удалить (в корзину или навсегда)
- `get_public_link` — опубликовать и получить публичную ссылку

## Важно про безопасность

- Никому не показывай значение `CONNECTOR_SECRET` и полный URL с ним —
  это по сути ключ доступа ко всему твоему Диску.
- Если URL всё же "утёк" — зайди в Render и смени `CONNECTOR_SECRET` на
  новый, потом обнови подключение в Claude.
